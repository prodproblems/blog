# Real Production Problems

**Real engineering problems. Explained in 3 minutes.**

Practical breakdowns of production incidents: what engineers observe, why systems fail, how to mitigate the incident, and how to prevent it from happening again.

## Latest articles

- [One Slow Database Query Took Down an API](articles/slow-database-query-api.md) — How a slow query can exhaust a connection pool and turn latency into an API outage.

## The approach

Every breakdown covers the incident, observable signals, customer impact, competing hypotheses, the failure mechanism, immediate mitigation, permanent fixes, trade-offs, prevention, and an FDE challenge.

> These articles use representative scenarios unless a specific, publicly documented incident is cited. Example metrics are illustrative, not claims about a particular company or outage.
